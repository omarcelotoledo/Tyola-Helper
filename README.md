# Tyola Helper

Tyola (pronuncia-se "Tai-ou-la") é um robozinho assistente que mora num celular antigo: uma chave inglesa, um olho com estrela e uma boquinha. Ela ouve, fala, mostra emoções, finge controlar o computador pela voz e conversa com IA (Tyola+).

Projeto de escola (trabalho de inglês: invenções que ainda não existem) feito pelo Theo.

**Abrir:** https://omarcelotoledo.github.io/Tyola-Helper/

- Toque na tela pra falar com ela (no Safari o microfone funciona direto).
- Menu ☰: modo apresentação, emoções, passeio (mBot), timer, idioma, formato iPhone 8.
- A chave de API da Tyola+ é colada no menu e fica salva só no aparelho; ela nunca vai pro código.
